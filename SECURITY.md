# Política de segurança

## Dados sensíveis

Não inclua dados de alunos, equipe, históricos, backups, arquivos `.env`, senhas, chaves ou tokens no repositório. Use apenas dados fictícios e anonimizados em exemplos e testes.

## Relato de vulnerabilidades

Não publique vulnerabilidades em issues. Avise o responsável pelo repositório de forma privada, incluindo uma descrição, impacto e passos de reprodução.

## Implantação

Mantenha o repositório privado, use HTTPS por um proxy confiável e configure todas as variáveis exigidas em `.env` antes de iniciar o serviço.
